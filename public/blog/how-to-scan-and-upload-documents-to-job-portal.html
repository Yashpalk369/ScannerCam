How to Scan and Upload Documents to a Job Portal

By Scanner.cam Team · Updated 31 Oct 2026 · 4 min read
Quick answer

To scan and upload documents to a job portal, first check the portal's exact requirements — file type, size limit, and which documents it wants — then scan each document as one clean PDF, name the files clearly, and upload them in the order the portal lists them. Confirm every upload shows a success message before you submit the application.

Job portals reject more applications on document technicalities than on qualifications: a sideways degree, a photo instead of a PDF, a file over the size limit, or a missing page in a transcript. The fix is a short, repeatable routine — check requirements, scan properly, name clearly, upload in order, verify — that works on every portal, from a company careers page to a government recruitment site. This guide walks through it, including what to do when an upload fails.

Check the portal's requirements first

Before scanning anything, read the portal's upload instructions carefully. Note the accepted file types (usually PDF, sometimes JPG), the maximum file size per document (commonly 2–10 MB), whether it wants one file per document or one combined file, and the exact document list — CV, degree, transcripts, experience letters, ID, and photo are typical. If the portal lists page limits or asks for documents "in order", follow that order exactly; recruiters review in the sequence you upload.

If the requirements are unclear, prepare one PDF per document. That format is accepted almost everywhere and is easy to split or combine later. Keep your originals safe: never upload the only copy of anything, and never send original paper documents through a portal that only asked for scans.

Scan each document as one clean PDF

Use your phone's built-in scanner or a browser scanner such as Scanner.cam — no app install needed. Scan in order, check every page in the preview, and export one PDF per document. For a degree or experience letter, include every page, including the back if it carries a stamp or signature. For an ID, capture front and back into the same file.

Check readability at full size, not as a thumbnail: a page that looks fine small can hide a cut-off signature or a blurred stamp. Keep each PDF under the portal's size limit — a clean scan of a few pages is usually well under a few megabytes. If a file is too large, rescan at normal resolution rather than shrinking a huge photo, which only makes text softer.

Name files the way recruiters expect

Use a consistent pattern: "surname-document.pdf", for example "ahmed-cv.pdf", "ahmed-degree.pdf", "ahmed-experience-letter-abc-company.pdf". Avoid spaces, special characters, and vague names like "scan001.pdf" or "document-final-final.pdf" — portals sometimes mangle odd characters, and a recruiter downloading twenty attachments should be able to tell which is which at a glance. If the portal renames uploads automatically, your clear names still help you verify you attached the right file to the right slot.

Upload in order, then verify before submitting

Upload one document at a time into its matching slot — CV into the CV slot, degree into the degree slot — rather than dragging everything into a single generic upload. After each upload, wait for the success indicator and, if the portal offers a preview, open it and confirm the right document loaded and every page is present. A surprising number of failed applications trace back to an upload that silently attached the wrong file.

Only press submit once every required slot shows its document. After submitting, save or screenshot the confirmation page and any application reference number, and keep your PDFs — if the employer asks you to resend a document later, you can do it in seconds instead of rescanning.

When an upload fails

If a file is rejected, check the three usual causes in order: wrong file type, file over the size limit, or a filename with characters the portal dislikes. Convert to the requested type, reduce size by rescanning at normal resolution, and rename with plain letters, numbers, and hyphens. If the portal itself errors, try a different browser, clear the upload and retry once, and avoid re-uploading the same file repeatedly — duplicate uploads can create duplicate applications. If it still fails, contact the portal's support with a screenshot and your application reference, and keep your deadline in mind: start uploads well before the closing time, not in the final hour.

Frequently asked questions

Should I upload one combined PDF or separate files?
Follow the portal's instructions. If it does not say, upload one PDF per document — it is the most widely accepted format and the easiest to verify.

What file size is safe for job portals?
Most portals accept 2–10 MB per file. A clean scan of a few pages is usually well under that; if yours is larger, rescan at normal resolution.

Can I upload photos instead of PDFs?
Only if the portal explicitly allows images. Otherwise, always send PDFs — photos get reordered, compressed, and sometimes rejected outright.

What if I upload the wrong document?
Most portals let you replace a file before submission. Delete the wrong upload, attach the correct one, and preview it before you submit.

Should I keep my scans after applying?
Yes. Keep the PDFs until the hiring process ends — employers often ask for a document to be resent, and a saved scan answers that in seconds.
