How to Scan a QR Code from a Screenshot

By Scanner.cam Editorial Team · Updated 11 Nov 2026 · 5 min read
Quick answer

To scan a QR code from a screenshot, open the screenshot in your Photos or Gallery app and use your phone's built-in QR reader — on iPhone, long-press the code in the photo; on Android, open it in Google Lens. You do not need a second phone, a printout, or a separate scanner app.

A screenshot is often easier to read than a live photo, because there is no camera shake, no angle, and no glare.

You cannot point your phone's camera at its own screen, so a QR code that arrives in a message, an email, or a web page can feel stuck. It is not. Every modern iPhone and Android phone can decode a QR code from a saved image — the same code your camera would read, decoded from the file instead of through the lens.

On iPhone: long-press the code in Photos

On an iPhone running iOS 16 or later, this takes about five seconds:

  1. Take the screenshot of the QR code, or save the image that contains it to your Photos app.
  2. Open the image in Photos and find the QR code.
  3. Press and hold your finger on the QR code for about two seconds. A menu appears with the link or action the code contains.
  4. Check the web address, then tap to open. Do not tap blindly — a screenshot can hide a malicious link just as easily as a printed code (see our safety guide below).

If the long-press does nothing, use Live Text instead: open the same image, tap the Live Text icon in the bottom-right corner, and tap the code it highlights. Live Text needs iOS 15 or later and an iPhone XS or newer. If neither works, update your phone — older iOS versions cannot read codes from saved images.

On Android: open it in Google Lens

Google Lens is built into Google Photos on almost every modern Android phone:

  1. Save the screenshot to your phone, or take one of the code on your screen.
  2. Open the image in Google Photos and tap it to view it full-screen.
  3. Tap the Lens icon at the bottom of the screen — it looks like a square viewfinder with a dot.
  4. Lens highlights the code and shows the link. Check the address, then tap it to open.

If you do not see the Lens icon, open the Google app instead, tap the camera icon in the search bar, then tap the gallery icon and choose the screenshot. On Android 15 and later, Circle to Search is another route: long-press the home button on the screen showing the code, circle it with your finger, and the decoded link appears.

On a computer: upload the image to Lens

On Windows or Mac, open the screenshot in your browser and search it with Google Lens — in Chrome, right-click the image and choose "Search image with Google", or upload the file at lens.google.com. Lens decodes the code and shows the link. Any free online QR decoder works the same way, but a well-known tool is the safer choice for an image you do not trust.

If the code will not scan

  • Crop the image so the code fills the frame. If the code is a small part of a busy screenshot, the reader may grab the wrong thing — or nothing at all. Crop tight, then try again.
  • Check all three corner squares are visible. A QR code needs its three large corner squares to be recognised. If one is cut off by the edge of the screenshot, take the screenshot again with the whole code in frame.
  • Check the resolution. A code shrunk to a tiny thumbnail loses the fine detail the reader needs. Use the original image, not a compressed preview from a chat app.
  • Straighten a rotated code. Most readers cope with rotation, but a code photographed at a steep angle inside a screenshot can still fail. Rotate the image upright and try again.
  • Clean up a low-contrast code. A code on a dark or patterned background is harder to read. Raising the brightness or contrast of the image before scanning sometimes helps.

Check where the code goes before you tap

A QR code in a screenshot is not safer than a printed one — it is the same hidden link, and the same scams apply. A code sent by a stranger, or one that arrived with an urgent message about a failed delivery or a locked account, deserves suspicion. Read the web address your phone shows you before you tap it: if it does not match the company it claims to be from, or it asks you to log in or pay, do not open it. Frequently asked questions

How do I scan a QR code from a screenshot?
Open the screenshot in your Photos or Gallery app and use the built-in reader — on iPhone, long-press the code in Photos; on Android, open it in Google Photos and tap the Lens icon. You do not need a second phone or a separate app.

Can I scan a QR code from a screenshot on iPhone?
Yes, on iOS 16 or later. Open the screenshot in Photos, press and hold the QR code for about two seconds, and tap the link that appears. On older iOS versions, use the Live Text icon in the bottom-right corner of the photo instead.

How do I scan a QR code from a screenshot on Android?
Open the screenshot in Google Photos and tap the Lens icon at the bottom. Lens decodes the code and shows the link. On Android 15 and later, Circle to Search also works — long-press the home button and circle the code.

Why won't my screenshot QR code scan?
Usually the image is the problem, not the code: the code is cropped, too small, low-resolution, or partly hidden. Crop the image so the code fills the frame, check all three corner squares are visible, and use the original image rather than a compressed chat preview.

Is it safe to scan a QR code from a screenshot?
The scan itself is safe — reading a code cannot infect your phone. The risk is the destination: check the web address before tapping, and never enter passwords or payment details on a page a random code opened.
