How Teachers Can Scan Exam Papers and Answer Sheets

By Scanner.cam Editorial Team · Updated 7 Nov 2026 · 4 min read
Quick answer

Teachers can scan exam papers and answer sheets by photographing each stack in batches, straightening and cropping each page, and merging them into one PDF per class or per student. A phone camera and a free browser scanner handle a whole set in minutes, with no photocopier or scanner app subscription needed.

Marking season means stacks of paper: exam scripts, answer sheets, marked work to return, and moderation samples to file. A flatbed scanner handles ten pages an hour if you are lucky; a phone handles a whole class set in one sitting. The workflow below is built for volume — batches, fixed setup, and one file per class — so the scanning never takes longer than the marking itself.

Set up for a whole class set

  1. Sort before you shoot. Stack the scripts in student order, or in the order you want the PDF. A sorted stack scans cleanly; an unsorted one produces a PDF you have to reorganise later.
  2. Fix the phone and the light. A phone stand and one steady light source from the side. Once the position is set, don't move it for the whole set.
  3. Decide the file plan. One PDF per class is the usual choice for filing and moderation; one PDF per student is better for returning work digitally. Pick one before you start.
  4. Keep a pen handy. Mark the top sheet of each batch with the student name or range, so a dropped stack can be re-sorted in seconds.

Scan the set in batches

  1. Shoot one script at a time, in order. Front page, then the following pages, then the next script. Work through the stack without skipping.
  2. Check the first script at full zoom. Answers in pencil and faint ink are the hardest to read — if the first script is sharp, the setup is right for the rest.
  3. After each batch of 10 to 15 scripts, check the thumbnails. Look for missing pages, duplicates, and upside-down sheets. Fix them now, while the stack is still in order.
  4. Merge each batch into a PDF. Name it by class and date, for example "Year-10-Maths-Midterm-Nov-2026.pdf". A clear name is what makes the file findable in June.
  5. File it immediately. Save the PDF to the school drive or your own storage before starting the next batch. A scanned set that sits on the phone is a set that can be lost.

Handle pencil, faint ink, and double-sided sheets

Student work is harder to scan than printed documents. Pencil fades in dim light, so add more light rather than using the flash — flash glare whites out pencil strokes. Double-sided sheets need both sides photographed; shoot front, flip, shoot back, and keep the sequence. If an answer runs across a page break, keep both pages — a marker needs the whole answer, not half of it. For homework and assignments your students submit to you, the same clean-capture standard applies in reverse — see how to scan homework assignments to submit online for what a good submission scan looks like, which is worth sharing with students who keep sending sideways photos.

Privacy and safekeeping

Exam scripts are student records. Keep the PDFs in the school's storage, not on a personal phone longer than the scanning session, and delete the phone copies once the files are saved. Scanner.cam processes everything in the browser, so the scans never upload anywhere during capture — but the finished PDF is your responsibility once you save and share it. If your school has a policy on where student work may be stored, follow it.

Common mistakes to avoid

  • Scanning an unsorted stack. Ten minutes of sorting saves an hour of reordering a PDF.
  • Skipping the batch check. A missing page found after the stack is re-filed means pulling the whole set out again.
  • Using the flash on pencil work. Flash kills pencil contrast. Use more side light instead.
  • Leaving finished PDFs on the phone. Phones get lost, reset, and run out of space. File the PDF the same day.
  • One giant file for everything. A single PDF for three classes is hard to share and slow to open. One file per class, clearly named.

Frequently asked questions

How can a teacher scan a whole set of exam papers quickly?
Sort the stack first, fix the phone and light in one position, then shoot in batches of 10 to 15 scripts, checking thumbnails after each batch before merging into one PDF per class.

What is the best way to scan answer sheets written in pencil?
Use bright side light and no flash. Pencil fades under flash glare, so add light from a lamp or window and check the first sheet at full zoom.

Should exam papers be scanned as one PDF per class or per student?
One PDF per class is best for filing and moderation; one PDF per student is better when returning work digitally. Choose before you start scanning.

Is it safe to scan exam papers with a phone?
Yes, if you file the PDFs in school storage and delete the phone copies afterwards. Scanner.cam processes scans in the browser, so nothing uploads during capture.

How do I scan double-sided answer sheets?
Photograph the front, flip the sheet, photograph the back, and keep shooting in order so the merged PDF reads front-back, front-back through the whole script.
